# Jaiswal Fertilizer Store

Premium demo storefront built with React + Vite, Node/Express, JWT authentication and JSON file storage. Login is name + 10-digit mobile (no OTP).

## Run locally (Windows PowerShell)

```powershell
npm install
npm run dev
```

Open http://localhost:5173. Keep the terminal running while you use the site.

## Cart & order flow
- Add products, increase/decrease quantities, and view a sticky cart summary.
- Checkout collects customer name, phone, state, district and delivery address.
- Optional browser live-location capture adds a Google Maps location link to the order.
- UPI or cash-on-delivery selection. Merchant UPI details must be supplied separately; UPI is confirmed over WhatsApp.
- Order summary is sent to WhatsApp **98395 32365** (wa.me/919839532365).
- Store map search: Bibiganj Bazaar Main Market, near Union Bank of India, Jaunpur, Uttar Pradesh.

Prices and product catalog are demo/indicative. Confirm stock, final prices and delivery with the store.
